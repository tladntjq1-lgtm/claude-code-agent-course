# AX Job Agent — 코딩/작업 규칙 (Conventions)

> "무엇을 만드는가"는 [SPEC.md](./SPEC.md), "지금 어디까지 했는가"는 [PROGRESS.md](./PROGRESS.md).
> 이 문서는 **"어떻게 작업하는가"** — 앞으로 정해지는 코딩/작업 규칙을 모아두는 곳.
> 새 규칙이 정해지면 이 문서에 계속 추가한다.

---

## 1. Notebook 3단 블록 규칙 (고정)

Notebook에 새 작업을 추가할 때는 예외 없이 아래 3개 셀을 하나의 세트로 작성한다.

1. **작업 계획 (Markdown Cell)** — 이번 블록에서 무엇을, 왜 하는지, 확인할 항목은 무엇인지
2. **실제 코드 (Code Cell)** — 계획에 필요한 코드. 코드가 길면 여러 Code Cell로 나눠도 되지만, 그 묶음 전체가 하나의 블록에 속한다
3. **실행 결과 해석 (Markdown Cell)** — 실행 성공 여부, 실제로 확인한 값, 예상과 다른 점, 다음 블록/STEP 진행 가능 여부

순서는 항상 **계획 → 코드 → 해석**이며, 해석 없이 다음 블록으로 넘어가지 않는다.
이 패턴은 STEP 단위뿐 아니라 STEP 내부의 하위 작업 단위에도 동일하게 적용한다.
